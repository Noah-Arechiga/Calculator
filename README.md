# 🔢 Calculator App
Welcome to my simple, responsive, and web-based calculator built using HTML, CSS, and JavaScript. This calculator supports basic arithmetic operations, exponentiation, sign toggling, and a clean UI interaction.

## ▶️ How To Use
1. Clone the repository in your terminal with the following command:
    * ```bash
       git clone https://github.com/Noah-Arechiga/Calculator.git
2. Change directories to get into the Calculator app folder by typing the following command:
    * ```bash
      cd Calculator
3. (macOS) Open the html file by typing the following command:
    * ```bash
      open index.html
4. (Windows) Open the html file by typing the following command:
    * ```bash
      start index.html
5. Enjoy!

## ✨ Features
* ➕ Addition, ➖ Subtraction, ✖️ Multiplication, ➗ Division
* 🔼 Exponentiation (^ operator)
* 🔄 Toggle sign (+/- button)
* 🧹 Clear (C) and delete last input (DEL) buttons

## Programming Languages and Frameworks Used
* HTML - used for the application structure
* CSS - used for the styling and layout of the calculator
* JavaScript - Used for the calculator logic and interactivity
